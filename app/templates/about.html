About Student Portal

Student Management System

Project Overview

The Student Portal is a web-based student management application developed using Python and Flask. It provides a simple and efficient way to register, manage and view student information.

Main Features

  • Student registration
  • Student profile management
  • Student photo upload
  • Student search
  • Student details
  • Edit student information
  • Delete student records
  • Student ID card generation
  • Printable student ID cards

Technologies Used

  • Python
  • Flask
  • Flask-SQLAlchemy
  • Flask-Migrate
  • SQLite
  • Flask-WTF
  • WTForms
  • Bootstrap

Purpose

This project demonstrates the development of a full-stack web application using Python, Flask, relational database management and modern web technologies.
